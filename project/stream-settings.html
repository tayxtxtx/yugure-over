Stream Settings
TWITCH SETUP
01 Stream Title & Note
The title shows in Just Chatting banner and as the big white game name in the Gaming overlay. The optional note replaces the small gray text in the Gaming overlay (e.g. death count, run info).
02 Stream Schedule
Shown on Starting Soon, End Screen and Stream Schedule. Up to 7 days. Days not added are grayed out in Stream Schedule.
03 Character Image (Stream Schedule page)
Paste an image URL to use a custom character, or click HIDE to remove it. Leave empty to use the default assets/character.png.
